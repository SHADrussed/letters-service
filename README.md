# Feedback Form MVP

## 🇷🇺 Описание

Форма обратной связи с отправкой на backend.

Функционал:

- Валидация полей
- Отправка на API
- Состояния: загрузка / успех / ошибка

## GB Description

Feedback form connected to backend API.

Features:

- Field validation
- API integration
- States: loading / success / error
